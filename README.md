# options-analysis

This was a project that aimed to find pricing disprecpencys between the price of a an option, and its excersion value.

TLDR: I just dont have the compute or api to really do this close to real time. Turns out that this is exactly what  market makers do not want the average person doing (i didnt realize this until much later).

Essentially, this type of arbitrage while mathmatically possible, individuals just dont have the compute or resources to pull this off. Market makers basically achieve this with immense resources and stop such things from happening in the stock market. I also doubt Python was the right language anyways.


Im leaving this here as an example of how to build a flask app with task based/distrubuted architecture.
